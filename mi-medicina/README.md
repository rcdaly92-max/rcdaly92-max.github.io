# Indicadores epidemiológicos · MI Medicina
Actividad: https://rcdaly92-max.github.io/mi-medicina/

## Activación de la recepción
1. Abrir MI Medicina: https://docs.google.com/spreadsheets/d/1yfitygIKWXCV4jSTQogN2L80MEIFBexNhOiRzCN3UkQ/edit
2. Extensiones > Apps Script. Sustituir el código inicial por el contenido de Code.gs de esta carpeta.
3. Guardar y ejecutar configurarMI. Autorizar el acceso.
4. Implementar > Nueva implementación > Aplicación web. Ejecutar como propietario; acceso Cualquier persona. Mantener la hoja privada.
5. Comunicar la URL /exec a ChatGPT para añadirla a config.js. No reutilizar la URL de QO, cuyo receptor solo acepta actividades de Química.
6. Verificar una entrega de prueba en INTENTOS y sus 12 filas en RESPUESTAS.

Antes de la activación, la página avisa que no puede enviar y ofrece un comprobante local. Después de activarla, solo confirma si el receptor verifica que el identificador se guardó. Cada participante introduce nombre, código y paralelo.

El registro es formativo. El servidor comprueba las respuestas contra una clave propia, pero la actividad pública no verifica identidad ni impide consultar las respuestas o repetirla.

Datos ficticios basados en el ejercicio de la clase 4. Se aclara la población de referencia y el seguimiento, y se distingue riesgo de tasa persona-tiempo.
