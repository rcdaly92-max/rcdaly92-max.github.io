# QO · Laboratorio molecular
Actividad de 12 preguntas basada en Unidad 1, Química orgánica, Clase 2.

## Activar recepción de respuestas
1. Abrir el archivo QO: https://docs.google.com/spreadsheets/d/1jU-eKdBcRkboBzaMkICY80xr0mgxGewIpEvC6XclS_o/edit
2. En Extensiones > Apps Script, pegar el contenido de `Code.gs` de esta carpeta y guardar.
3. Ejecutar `configurarQO` y autorizar el acceso a la hoja.
4. Implementar > Nueva implementación > Aplicación web. Ejecutar como propietario; permitir acceso a Cualquier persona. La hoja QO debe permanecer privada.
5. Copiar la URL terminada en `/exec` y comunicarla a ChatGPT para incorporarla en `qo/config.js` como `window.QO_URL`.
6. Realizar una entrega de prueba identificada como PRUEBA DOCENTE y comprobar sus filas en INTENTOS y RESPUESTAS antes de distribuir la actividad.

La hoja registra nombre, código, paralelo, cada respuesta, respuesta correcta, aciertos y nota sobre 10. Se puede descargar como Microsoft Excel con el nombre QO.xlsx. No se conecta al archivo de Higiene.

Hasta completar la activación, la actividad muestra claramente que el envío está pendiente, conserva el avance en el navegador y permite descargar un comprobante JSON. Nunca anuncia una entrega exitosa sin confirmación del servidor.
