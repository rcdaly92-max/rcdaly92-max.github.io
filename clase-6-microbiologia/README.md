# Clase 6: Microbiología de los alimentos — Higiene y sanidad alimentaria

Actividad individual formativa para estudiantes de primer año de Gastronomía UTE. Doce casos autocorregibles sobre bacterias, virus, hongos y factores CHATTO.

## Publicación
Sitio: https://rcdaly92-max.github.io/clase-6-microbiologia/

## Integración
Reutiliza el endpoint de Google Apps Script de `Registro_Google_Sheets_Juegos_UTE`.
Registra un solo intento con identificador `submission_id` y lo verifica por consulta de estado.
El JSON envía `class_name: Clase 6`, `activity_id: clase-6-microbiologia`, `score_correct`, `score_total: 12`, `answers` y `reflections`.
Para efectos del registro, nota /10 = aciertos * 10 / 12; la reflexión queda como revisión docente.
